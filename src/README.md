# Source folder

Folder containing all source file for the PoC to work.

## ./benchmarks

Contains C file to run the primitives benchmarks that are then supplied to Abacus tool. Some file were taken from https://github.com/ageimer/sok-detection as well as https://github.com/hibazhd/abacus-project/.

## common.c and common.h

Files used for defining functions and values that are shared by all the benchmarks. These files has been sampled from https://github.com/ageimer/sok-detection with the difference that we only target Abacus tool.
